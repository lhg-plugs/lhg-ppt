# /lhg-ppt:ppt-outline —— 大纲先行

用户输入在 `$ARGUMENTS` 中：`"<主题或文档路径>" [--pages <目标页数>]`。

**定位**：只出大纲，不生成页面。适合"我先看看思路对不对"的阶段，
大纲确认后再跑 `/lhg-ppt:ppt` 生成。

## 流程（加载 lhg-ppt-outline 全程指导）

### 1. 定一句话结论
先回答：听完这份 PPT，听众应该记住哪一句话？写下来，这是全文的北极星。

### 2. 金字塔搭骨架
按 lhg-ppt-outline 第 3 步输出：
- 顶层：核心结论（1 句）
- 中层：分论点（3-5 个，MECE 不重不漏）
- 底层：每页一句话标题 + 3 个以内要点 + 需要的数据/图表

### 3. 场景适配
- 述职：成绩→方法→规划，数字先行
- 融资：痛点→方案→数据→团队→融资需求
- 答辩：背景→方法→结果→创新点→不足与展望
（详见 lhg-ppt-outline 第 4 节场景模板）

### 4. 输出
存为 `output/<主题>-outline.md`，并给用户一份"大纲确认清单"：
每页标题连起来读一遍，是否像一篇通顺的短文？是 → 通过；否 → 返工。

## 硬规则
- 每页标题是完整的一句话观点，不许是"背景""介绍"这种名词堆砌。
- 要点超过 5 个 → 拆页。
- 需要但还没有的数据标 [待补充]，不许编。
